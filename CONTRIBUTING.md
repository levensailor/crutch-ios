# Contributing

Create a new feature branch for each change.

1. Branch from `main` with a descriptive name, such as `feat/lyrics-manager`.
2. Make the change and keep it focused.
3. Add or update tests for behavior changes.
4. Open a pull request.
5. Describe why the change should be added to the repository, what changed, and how it was verified.

Do not commit `.env` files, virtual environments, generated build folders, or local artifacts.
